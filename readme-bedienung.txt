Tonibox Bedienung:
Einschalten: Ein kurzes Drücken eines der beiden Ohren schaltet die Toniebox ein.
Ausschalten: Die Toniebox schaltet sich automatisch aus, wenn sie 10 Minuten lang nicht benutzt wird oder wenn ein Hörbuch zu Ende ist.
Lautstärke: Das kleine Ohr dient zum Leiserstellen, das große zum lauter stellen.
Abspielen/Anhalten: Ein Tonie auf die Box stellen startet die Wiedergabe, das Entfernen stoppt sie. 
Vor- und zurückspulen: Die Toniebox wird um etwa 45 Grad zur Seite gekippt, bis ein Signalton ertönt. 
Kapitel oder Lieder wechseln: Ein seitlicher Klaps auf die Box kann zum Überspringen von Kapiteln oder Liedern verwendet werden. 


jimbabox Bedienung:
Ein-/Ausschalten: Knopf
Lautstärke: 2 Knöpfe (+, - oder Tonibox Ohren)
Abspielen/Anhalten: Figur auf Box stellen.
Vorspulen: Box um ca. 45 Grad nach rechts kippen oder Button drücken
Zurückspulen: Box um ca. 45 Grad nach links kippen oder Button drücken
Kapitel oder Lieder wechseln, vor: Ein seitlicher Klaps von links auf die Box kann zum Überspringen von Kapiteln oder Liedern verwendet werden. Oder Button
Kapitel oder Lieder wechseln, zurück: Ein seitlicher Klaps von rechts auf die Box kann zum Überspringen von Kapiteln oder Liedern verwendet werden. Oder Button
